# Birthday Surprise

## Personalise
Edit `js/config.js`: her name, your name, number of candles, the letter, and the 8 reasons.
You can also set names in the link: `your-site.vercel.app/?name=Priya&from=Arjun`

## Deploy on Vercel
1. Upload the contents of this folder to the root of your GitHub repo (index.html must be at the top level).
2. In Vercel: Framework Preset = Other, leave Build Command and Output Directory empty.
3. Deploy.

## Files
- `index.html` – page structure
- `css/style.css` – all styling and animations
- `js/config.js` – your personal text
- `js/script.js` – animations, fireworks, sound, interactions
